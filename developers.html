REST API 一览

所有资源都遵循统一风格：/v1/{resource}，认证用 Bearer Token，返回 JSON。

  • POST /v1/assistants — 创建助手
  • POST /v1/assistants/{id}/invoke — 触发对话
  • POST /v1/tasks — 创建定时任务
  • GET /v1/runs/{id} — 查询执行结果
  • POST /v1/skills — 注册私有技能
curl · POST /v1/assistants/{id}/invoke
curl https://api.agentz.com/v1/assistants/asst_8H4/invoke \
  -H "Authorization: Bearer $AZ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "生成华南仓昨日异常单速览",
    "stream": false,
    "context": { "warehouse": "SCN" }
  }'

SDK：3 行代码上手

Python / Node / Go 三语言官方 SDK，自带流式响应、自动重试、详细类型。

Python SDK
from agentz import Client

client = Client(api_key="...")
result = client.assistants("asst_8H4").invoke(
    "生成华南仓昨日异常单速览"
)
print(result.output_text)
