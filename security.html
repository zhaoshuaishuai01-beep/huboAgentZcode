安全设计四层模型

L1 · 运行时隔离

每个助手任务在独立容器中跑；网络默认拒绝，仅放通 MCP 白名单端点。

L2 · 工具权限

MCP 工具按"角色 × 助手 × 用户"三维授权；危险操作必经人工确认。

L3 · 数据治理

PII / 敏感字段自动脱敏；上下文不出域，企业可指定模型驻地。

L4 · 审计与回放

所有事件写入不可篡改日志；任何一次决策都可"录像回放"。
