AgentZ 使用手册

这本手册帮你 5 分钟创建第一个助手，30 分钟把团队第一个例行报表交给 AgentZ。

5 分钟快速上手

跟随下面 4 步，你将创建一位"出库数据分析师"助手，让它每天早 8 点自动生成华南仓日报。

第 1 步 · 创建助手

登录 AgentZ → 顶部「+ 新建助手」→ 填写以下信息：

  • 名称：出库数据分析师
  • 头像：选择肖像 / 矢量插画 / 数字艺术任一预设
  • 描述：负责每日华南仓出库数据分析与日报生成
给助手起一个易于识别的名字 —— 当团队里有 20 个助手时，这件事会救你的命。

第 2 步 · 配置三段式 Prompt

AgentZ 的 Prompt 由三段组成，建议这样写：

[Role Definition]
你是华南区出库数据分析师，5 年快消行业经验，熟悉 WMS / TMS 字段。

[Work Instructions]
1. 收到数据询问 → 先用 erp.query 拉原始数据
2. 用 xlsx 技能整理透视表
3. 输出 3 条洞察 + 1 条行动建议
4. 如发现异常立刻 @ 仓主管

[User Context]
仓库：华南 (SCN) · 业务线：日化 · 当前关注指标：异常单率、爆品库存周转

第 3 步 · 挂载技能

在「技能」面板勾选：

  • xlsx — Excel 读写与透视
  • pptx — PPT 自动制作
  • internal-erp — 私有 MCP，已由管理员预配

第 4 步 · 配置定时任务

开启「定时任务」开关并填写：

name: scn-daily-report
cron: "0 8 * * *"      # 每天 8:00
instruction: 请生成华南仓昨日出库日报 PPT，并推送到运营群
workdir: /projects/scn-daily
max_runs: 365

点击「保存并启用」。明天 8:00，你会在钉钉群里收到第一份自动产出的日报。

核心概念

AgentZ 有四个核心概念，理解了它们就理解了整个产品：

  • Assistant（助手） — 一个领域专精的 AI 实体，有角色 / 工作指令 / 上下文
  • Skill（技能） — 一段被打包好的"做事方法"，可被多个助手挂载
  • MCP Tool（外部工具） — 通过 MCP 协议接入的业务系统能力
  • Scheduled Task（定时任务） — 让助手按计划主动执行

导入与管理技能

支持两种导入方式：

  • Git URL：直接从 GitHub / 内部 GitLab 拉取
  • ZIP 上传：本地打包好的技能包

自建技能

一个最小可用的技能只需一个 skill.yaml + 入口脚本：

name: tag-product
version: 1.0.0
entrypoint: ./main.py
inputs:
  - name: product_name
    type: string
outputs:
  - name: tags
    type: array

配置 MCP 连接

在「外部工具」面板点「+ 新增 MCP」，选择通道类型：

  • STDIO：适合本地命令行类工具
  • HTTP：适合标准 REST 服务
  • SSE：适合需要流式返回的场景

个人 & 团队设置

包含主题、语言、模型路由、配额管理等。详细字段见管理员手册。
